# Android 遠端字幕

原生 Kotlin／Android Views 手機字幕視窗，Android 8.0（API 26）以上可用。與 Stream Translator 電腦連到同一個區域網路，讀取公開字幕分享服務，不需要權杖，也不會呼叫管理 API。

## 建置

使用 JDK 17、Android SDK 36、Gradle 8.14.3、Android Gradle Plugin 8.13.2、Kotlin 2.2.0。以 Android Studio 開啟本目錄，讓 IDE 在本機產生 `local.properties`，或自行在該檔指定 `sdk.dir`。不要提交此檔。

此專案已包含 `gradle-wrapper.jar`、啟動腳本與 wrapper 設定，無須另外產生 wrapper。在本目錄執行：

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
```

Unix 可用 `sh gradlew assembleDebug`（或賦予執行權限後 `./gradlew assembleDebug`）。APK 位於 `app/build/outputs/apk/debug/app-debug.apk`；debug 簽章由 Android 工具自動產生，不需自備 keystore。

正式版 APK 以 `assembleRelease` 建置。簽章資訊放在 repo 以外的 properties 檔（`storeFile`、`storePassword`、`keyAlias`、`keyPassword`），以 Gradle 屬性或環境變數 `STREAM_TRANSLATOR_SIGNING` 指定路徑；未指定時正式版 APK 不簽章。之後的版本必須使用同一把金鑰，使用者才能直接覆蓋安裝。離線建置須事先快取版本目錄內的依賴、Gradle 分發檔及 SDK，再加上 `--offline`。

已在 Windows 上以上述版本建置成功，`testDebugUnitTest` 的 47 個測試通過（連續多次執行均通過），並於 Android 16 實機連線 v1.6.0 電腦端（經 HTTPS 反向代理）驗證主畫面、設定頁、懸浮字幕拖曳與鎖定。

## 電腦端與手機端

1. 在電腦的 Stream Translator 設定開啟「字幕分享」，保留公開服務預設連接埠 **8765**，並啟動翻譯。
2. 在 Windows 終端執行 `ipconfig`，找目前 Wi-Fi 或乙太網路介面的 IPv4 位址，例如 `192.168.1.10`。不要使用 `127.0.0.1`、VPN 或虛擬網卡位址。
3. 手機連到相同 LAN／Wi-Fi，輸入該位址並點「連線」。若連不上，檢查電腦防火牆的私人網路 TCP 8765 入站規則，以及基地台的用戶端隔離設定。
4. 可輸入 `192.168.1.10`、`192.168.1.10:8765`、`http://host:8765` 或分享頁網址；會記住上次的位址。省略連接埠時補 8765，分享頁尾 `desktop`／`mobile`／`subtitle`、查詢參數與片段會移除；保留反向代理的路徑前綴。
5. 點字幕區域可隱藏／顯示控制項。直向、橫向均支援，最新字幕在底部；連線期間保持螢幕開啟。一般模式離開應用程式會中斷連線，懸浮模式則由服務持續連線。

## 懸浮字幕

點「懸浮字幕」，在 Android 13 以上允許通知，並於系統畫面允許「顯示在其他應用程式上層」，再返回應用程式。這時可以切換到 YouTube 等其他應用程式。

懸浮視窗只顯示字幕，沒有工具列、按鈕或連線狀態。拖曳文字可移動，純垂直拖曳保留水平置中；雙指縮放即時調整原文與譯文字級，手勢結束時保存一次；雙擊開啟主畫面。直向與橫向各自保存位置。懸浮字幕運作時，主畫面下方改顯示「懸浮字幕顯示中」以避免雙層重疊。主畫面的「關閉懸浮字幕」移除視窗；「中斷連線」或通知的「停止」會結束連線與懸浮服務。懸浮視窗僅在翻譯已連線（`CONNECTED`）期間保留 `KEEP_SCREEN_ON`。

已啟用自動連線時，返回主畫面或設定頁會使用保存的主機恢復已停止的連線；手動中斷或通知停止會停用自動連線。主畫面狀態標籤會區分「已連線・辨識中」與「已連線・等待語音辨識」。

長按字幕可鎖定觸控穿透，從通知的「解除鎖定」恢復操作；設定也可切換「預設鎖定」。摺疊狀態的靜音通知內文會顯示連線狀態與鎖定提示（例如「已連線・已鎖定，展開通知可解除」或「已連線・長按字幕可鎖定」），展開後提供鎖定／解除鎖定、設定與停止動作，點通知本體返回主畫面。若通知權限被關閉，穿透會停用。所有支援的 Android 版本在鎖定穿透時，均將整個視窗 alpha 設為 0.79，以符合系統對遮蔽觸控的限制。

設定頁使用 Material 3，頂端 160dp 預覽與全螢幕／懸浮字幕共用繪製元件，可用「懸浮樣式／全螢幕樣式」切換預覽，以檢查各自的背景設定。滑桿隱藏刻度點，色票自動換行並對背景色提供深色調色盤（且保留自訂顏色選取狀態），開關列將標題與說明置於左側、開關置於右側。字級、字重、外框、陰影、色彩、全螢幕與懸浮各自的背景不透明度、筆數與寬度會立即保存並套用。「重設位置」回到畫面底部中央。

服務採用 `specialUse` 前景服務類型：用途是使用者明確啟用、持續顯示的即時字幕覆蓋視窗。Manifest 包含 `FOREGROUND_SERVICE_SPECIAL_USE` 和用途 property；API 34 以上明確傳入該類型。未採 `dataSync`，以免將長時間字幕顯示綁定資料同步的時限。服務由可見 Activity 啟動、不設開機自動啟動、回傳 `START_NOT_STICKY`。若上架商店，仍需按商店政策申報 specialUse 用途；本專案尚未進行商店審核；實機只驗證過 Android 16。

## 預設值與協定

- 原文 20sp、譯文 24sp，範圍 10～200；全螢幕顯示 5 筆，懸浮顯示最新 2 筆。
- 原文、譯文預設開啟；延遲、鎖定預設關閉；原文 `#55FFFF`、譯文 `#FFDD00`。
- 全螢幕字幕背景預設 100% 黑色，懸浮字幕背景預設 0%（完全透明），舊版共用不透明度設定升級時會將懸浮背景不透明度遷移為 0%，搭配黑色 3dp 外框與 4dp 陰影；可設定圓角背景色及 0～100% 不透明度。懸浮寬度（直屏）預設為螢幕的 92%，橫屏時寬度自動調為直屏的 1.5 倍（不超過螢幕）；沒有文字時視窗隱形但保持掛載。
- 僅存取 `/api/translation/active-task`、`/api/translation/stream/{task_id}`、`/api/translation/status/{task_id}`，不跟隨 HTTP 重新導向。
- 無工作每 3 秒輪詢；工作期間先每 2 秒檢查狀態。狀態端點回傳 404 時，除非內容是 `{"detail":"Task not found"}`（任務結束）或字幕分享已關閉，其餘 404（FastAPI 的 `Not Found`、v1.6.0 SPA 後備路由的 `Not found`、代理錯誤頁）都視為端點不存在，該次連線停用狀態輪詢，改為每 5 秒查詢 active-task；任務不同或消失才判定結束。正常 EOF 也使用相同降級規則，v1.6.0 電腦端可透過 active-task 降級機制運作。404 `{"detail":"Task not found"}` 直接表示任務結束，不停用後續任務的狀態輪詢。SSE `event: status` 搭配 `{"status":"completed"}`（或 `"stopped"`／`"error"`）也直接判定任務結束。 active-task 本身回傳這類 404 時顯示「找不到字幕分享服務，請檢查網址」，例如反向代理路徑設錯。
- SSE 的 asr_ready:true 或任何字幕事件都能確認辨識已就緒，後續未就緒狀態不會蓋掉字幕提供的證據。SSE 無讀取逾時；一般 JSON 請求 15 秒讀取逾時。連續三次存活查詢失敗會取消半開串流並重連。
- 串流結束或連線失敗依 1、2、5、10、10… 秒重試；收到字幕或串流存活至少 5 秒後重設退避。
- `SubtitleRepository` 是整個程序唯一連線持有者；切換主機會先取消並等待舊連線結束，再建立新連線。取消會關閉 OkHttp 請求及阻塞中的串流讀取。
- 歷史最多保留 500 筆。比對依原始 Python 順序：segment_id、時間戳、相同原文與兩端時間容差、id。時間戳優先 backend_timestamp；模糊比對由最新列往前找。參考檔容差實際為 **50 毫秒**，包含需求提到的 1 毫秒偏移。只覆寫事件有提供的欄位。

`testDebugUnitTest` 包含 Robolectric UI／生命週期測試、MockWebServer 協定／連線測試，以及網址、識別比對與容差邊界、更新與歷史上限、SSE 行解析、重連退避等 JVM 測試。UI 與實際 LAN 連線仍需裝置驗證：尤其旋轉、Wi-Fi 中斷後恢復、權限拒絕／撤回、穿透通知、主機切換與服務停止。
