Stream Translator v1.4.4 更新說明
=================================

主要修正
--------
- 修正部分 Windows 電腦會誤用系統 PATH 中舊版 yt-dlp.exe 的問題。
- 串流擷取現在固定優先使用目前套件 runtime 內的 yt-dlp 模組。
- 打包前仍會更新三端 runtime 與 CPU ASR Sidecar 內的 yt-dlp。
- 新增正式套件路徑驗證，若 yt-dlp 指向套件外部會停止發布。

更新方式
--------
- 使用 App Update 時請先完全關閉舊版程式，再覆蓋程式檔案。
- config.yaml、models、output、srt、logs 及已下載模型可以保留。
- CUDA、CPU、ROCm 使用者請下載與目前安裝版本相同的 App Update。

完整異動內容請參閱 RELEASE_NOTES_v1.4.4_zh-TW.md。
