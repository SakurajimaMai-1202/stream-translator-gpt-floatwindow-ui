# Stream Translator v1.4.3 更新說明

v1.4.3 主要改善操作介面、浮動字幕、模型下載與語音辨識穩定性。現有的即時轉譯、四種音源、字幕分享、模型管理、術語表及進階設定功能均予以保留。

## 介面與操作體驗

- 全面更新主介面，統一首頁、設定、ASR／LLM 模型、術語表、教學、字幕外觀及字幕分享頁的色彩、字級、間距、面板與操作狀態。
- 改善導覽層級、按鈕尺寸、鍵盤焦點、窄螢幕排版、長路徑換行及減少動態效果偏好支援。
- 補強對話框標題與無障礙語意，使設定及模型管理操作更清楚。
- 保持透明字幕頁與使用者自訂字幕樣式獨立，主介面改版不會覆蓋字幕外觀設定。

## 浮動字幕

- 新字幕加入時改用平滑捲動與邊緣淡出，舊字幕會自然離開視窗，不再突然切換或殘留一排。
- 統一字幕位於螢幕頂部或底部時的上下留白，避免內容貼邊或兩種位置間距不一致。
- 修正預覽字幕與最終翻譯時間戳僅相差數毫秒時被顯示為兩筆的問題；同一段字幕會直接補上翻譯。
- 原生 Qt 浮動字幕與網頁備援字幕採用相同的字幕識別規則，並優先使用 `segment_id` 更新既有內容。

## 模型下載

- 改善大型 ASR 模型下載，支援四連線分段下載與即時進度回報。
- 修正下載畫面停在 0% 或看似卡住的問題；每接收一段資料即更新已下載容量與百分比。
- 保留中斷續傳、檔案完整性檢查及多連線失敗時退回單線下載的安全機制。
- Hugging Face 與 ModelScope 下載流程加入平行下載設定，縮短大型模型等待時間。

## 語音辨識與執行穩定性

- 修正舊設定中的 ASR 布林旗標可能覆蓋首頁新選擇的問題；每次開始任務時會正規化為單一辨識引擎。
- 修正 NVIDIA Parakeet TDT 在低精度 CUDA 模式下可能發生解碼資料型別不一致的問題。
- 管線背景工作發生錯誤時會回報並結束任務，避免介面持續顯示執行中或無限等待。
- JSON 字幕事件啟用時不再額外輸出可被誤判為第二筆字幕的文字副本。
- 改善任務停止與佇列收尾流程，降低殘留工作與停止卡住的機率。

## 開發與相容性

- 正式打包流程會先將各建置環境與 runtime 的 `yt-dlp` 更新至當下最新版；更新或版本驗證失敗時會停止打包，避免發布過期版本。
- 將 `vue-tsc` 更新至支援 Node.js 24 的版本，完整 `npm run build` 已可正常完成型別檢查與 Vite 建置。
- 已完成四種音源的啟動、運行與停止回歸，並驗證 URL／本地檔案字幕 SSE、字幕設定讀寫及桌面／行動字幕頁載入。
- 已驗證最新版前端由 FastAPI／Qt 應用程式實際載入，原生 Qt QPainter 浮動字幕 renderer 正常啟動。

## 發布前狀態

- 原始碼、前端正式建置與針對本次問題的自動測試已完成。
- CUDA、CPU、ROCm 正式套件已重新建置，Full 與 App Update 執行檔均通過健康檢查。
- Full 壓縮檔、分卷重組及乾淨解壓驗證均已完成，三端套件內的 `yt-dlp` 已更新至建置當下最新版。
