Stream Translator v1.4.7 更新說明
=================================

主要更新
--------
- 首次啟動可選簡單或進階模式，選擇會保存並可隨時切換。
- 簡單模式依輸入語言自動選擇 CPU ASR：中文 SenseVoice、日文 Parakeet、其他支援語言 Parakeet v3。
- 翻譯後端放到簡單模式首頁，直接接 OpenAI、Gemini 或 OpenAI-compatible API。
- 首次選擇模式時會檢查 CPU ASR Runtime，並預先準備三個推薦 ASR 模型。
- 修正小視窗無法切回簡單模式，以及下拉選單距離過遠的問題。
- 修正更新器可能因 Qt DLL 版本混用而無法載入 PyQt6.QtCore 的問題。
- 改善新版 llama.cpp 與 Hy-MT 的啟動相容性，Flash Attention 改為 auto、Hy-MT 預設停用 mmap，並將 llama.cpp 日誌獨立記錄。
- 本機 LLM 開關每次啟動程式時預設關閉，避免自動占用硬體資源。
- 浮動字幕依視窗高度自然向上捲動，先捲出原文並保留完整中文翻譯；控制按鈕閒置時會自動隱藏。
- 修正浮動字幕時間／延遲顏色、設定預覽位置、最小高度顯示，以及介面模式選單與版本號間距。

更新方式
--------
- 新手最簡單的方式是下載 CPU Full 包，使用 CPU ASR，再設定 API 翻譯。
- CUDA、CPU 與 ROCm App Update 只能套用到相同 Profile。
- config.yaml、models、output、srt、logs 及已下載模型可以保留。

完整異動內容請參閱 RELEASE_NOTES_v1.4.7_zh-TW.md。
