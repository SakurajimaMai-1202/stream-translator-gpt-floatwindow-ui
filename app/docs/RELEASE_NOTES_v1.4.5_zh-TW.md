# Stream Translator v1.4.5 更新說明

v1.4.5 修正 App Update 第一次下載可能出現 SHA-256 mismatch、第二次才成功的問題。

## 更新下載修正

- 更新暫存檔名稱加入該資產的 SHA-256 前綴，不同版本不再共用同名 `.part` 檔案。
- 保留同一版本下載中斷後的續傳能力。
- 自動移除舊版更新器留下的未分版暫存檔。
- 校驗失敗時會在同一次操作中刪除損壞檔案並自動完整重抓一次，不必再次按下下載按鈕。
- 新增舊版暫存檔存在時仍能第一次下載成功的回歸測試。
- v1.4.5 App Update 以新的分卷資產名稱發布，避開 v1.4.3／v1.4.4 更新器可能留下的同名暫存檔。

v1.4.4 的套件內 yt-dlp 路徑修正，以及 v1.4.3 的介面、浮動字幕、模型下載與 ASR 穩定性更新均完整保留。
