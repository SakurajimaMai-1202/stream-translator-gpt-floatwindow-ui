# Stream Translator v1.5.0

發布日期：2026 年 10 月 10 日

重新打包更新：2026 年 10 月 11 日

本次更新帶來全新深色介面、指定應用程式音訊擷取與本機翻譯顯卡選擇，並改善首次設定、翻譯品質、字幕顯示及更新體驗。

## 主要更新

### 全新介面與更清楚的設定

- 統一首頁、模型管理、設定與字幕控制介面的視覺風格，改善操作層級與窄視窗顯示。
- 將常用設定集中呈現，進階選項可依需要展開，讓模型選擇與參數調整更方便。
- 改善深色選單、鍵盤操作及焦點提示；字幕仍可自訂字型、顏色、透明度與位置。
- 改善桌面首頁下拉選單的開關與選取反應，減少版面重算、模糊與動畫成本；設定保存改為背景執行，降低保存期間的後端停頓。
- Windows 桌面控制介面預設使用軟體渲染，改善部分顯卡環境的卡頓與繪製殘影；ASR 與本機翻譯仍可照原設定使用 GPU。

### 指定應用程式收音

- 可直接選擇正在執行的應用程式作為音訊來源，並在開始辨識前測試收音。
- 目標應用程式關閉時會停止擷取並顯示提示；重新開啟後請重新選擇音訊來源。

### 本機翻譯與顯卡選擇

- 支援手動指定本機翻譯使用的顯卡，並顯示模型的 GPU 載入狀態。
- 自動選擇優先使用獨立顯卡；NVIDIA 優先使用 CUDA，AMD 與 Intel Arc 獨顯建議使用 Vulkan。
- 新增 Index-Translate-2B 與 Index-Translate-9B GGUF 推薦，提供模型大小與顯存需求參考。
- 修正部分模型參數無法正確保存或載入的問題。

## 改善與修正

- **首次設定：** 依音訊來源與辨識語言準備入門模型，並更清楚地顯示來源與模型的準備狀態。
- **來源檢查：** 改善直播網址、本機影音、系統音訊與麥克風的收音測試及錯誤提示。
- **翻譯設定：** HY-MT2 與 Index 分別保存設定，避免切換模型時互相覆寫；改善相容 API 的回覆處理及試譯提示。
- **繁體中文：** 統一繁體中文輸出處理，改善術語、上下文與翻譯風格的一致性。
- **字幕顯示：** 改善短片段與日文未完句的字幕銜接，清理非字幕標記及多餘診斷文字。
- **啟動穩定性：** 修正 CPU 版本的部分啟動問題，改善顯卡辨識與本機翻譯啟動錯誤提示。
- **手動更新：** 支援 App Update ZIP 與分割包，提供檔案完整性檢查、備份及失敗回復，保留既有模型、設定與輸出檔案。
- **直播解析：** 套件內的 yt-dlp 更新至 `2026.10.10.233141.dev0`，改善 YouTube 等直播來源的相容性。

## 下載與版本選擇

| 套件 | 適用情境 |
| --- | --- |
| CPU | 使用 CPU 語音辨識，或搭配線上翻譯服務 |
| CUDA | 使用支援 CUDA 的 NVIDIA 顯示卡 |
| ROCm Experimental | AMD 實驗性版本；相容性依顯卡、驅動與模型而異 |

- **新安裝或切換套件類型：** 下載對應的 Full 完整包。
- **更新既有安裝：** 下載與原安裝類型相同的 App Update 更新包。
- **CPU ASR Sidecar：** 供原本使用獨立 CPU ASR 元件的配置更新使用；CPU 完整包無須另外安裝。

CUDA 完整包共有 **3 個分卷**，更新包共有 **2 個分卷**。請下載同一套件的全部分卷並放在同一資料夾。完整包可使用 `merge-full-package.bat` 合併；更新包可在手動更新器直接選擇 `.zip.part01`。

## 更新方式

本次維持 v1.5.0 版本號。已安裝先前 v1.5.0 的使用者，請重新下載本次 App Update 並使用手動更新器；分卷與校驗檔須全部取自本次發布，不可混用舊檔。

1. 備份 `config.yaml`、Cookies、術語與自訂規則，停止正在執行的辨識與翻譯任務。
2. 下載對應的 App Update 及 `SHA256SUMS-v1.5.0.txt`；使用分割包時，請確認所有分卷已下載完成。
3. 開啟手動更新器，選擇 ZIP 或 `.zip.part01`，依畫面提示完成更新。
4. 更新後確認版本為 **v1.5.0**，再啟動原本使用的來源、辨識模型與翻譯服務。

## 使用提醒

- 指定應用程式收音需要 Windows build 20348 以上。瀏覽器可能共用程序，無法保證只擷取單一分頁或視窗的音訊。
- 本機翻譯的顯卡選擇與 ASR 套件類型分別設定；切換翻譯顯卡不會改變已安裝的 CPU、CUDA 或 ROCm 套件類型。
- 若要測試桌面控制介面的 GPU 加速，可使用 `--enable-webview-gpu` 啟動；此選項只影響 WebView 介面渲染。
- 直播來源仍可能受網站變更、地區限制、登入狀態與 Cookies 影響。
