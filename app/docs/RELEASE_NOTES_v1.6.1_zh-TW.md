# Stream Translator v1.6.1

發布日期：2026 年 11 月 25 日

本次更新把推薦的本地翻譯模型改為 Hy-MT3 7B，改善 Index-Translate 的翻譯品質，CPU 版新增 Haas 日文辨識模型，主視窗改用 WebView2 讓操作更順暢，並修正 YouTube 直播暫停後不會重連等多項問題。

## 主要更新

### 翻譯

- **推薦模型改為 Hy-MT3 7B：** 支援 Hy-MT3 系列模型，選擇推薦模型時自動套用建議參數。Hy-MT3 可以使用 Flash Attention（Hy-MT2 仍會自動關閉）。
- **Hy-MT3 1.8B 自動關閉前文：** 這個模型會把前文一起翻出來，程式偵測到後會自動關閉前文並在設定頁說明。
- **Index-Translate 翻譯更穩定：** 前文改用一行簡短提示，大幅減少把前文混進翻譯或輸出成其他語言的情況，殘留的片假名也明顯變少。另外加上過短句、前文重複與重複迴圈的防護。
- **繁體中文只轉字形，不改用詞：** 翻譯結果不再被改寫成台灣用語（例如「數據」不會變成「資料」、「溢出」不會變成「溢位」）。語音辨識結果維持原本的轉換方式。
- **短句假名處理更準確：** 長音「ー」、小寫母音、拉長的敬稱與片假名動物名稱等都能正確轉成中文，暱稱不會被誤改。
- 翻譯設定頁的說明改用「Hy-MT 系列」與「Index-Translate 系列」稱呼。

### 語音辨識

- **CPU 版新增 Haas 日文模型（量化版）：** 約 480 MB，在我們的日文直播測試中，錯字率約 12–15%，原本的 CTC 模型約 22%。可在模型管理頁下載；GPU 版會顯示無法使用的原因。
- **修正 Qwen3-ASR 在背景音樂或雜音時重複上一句：** 偵測到辨識結果只是照抄前文時，會自動不帶前文重新辨識一次。
- ASR 模型改用白話名稱，並標示模型大小。

### 直播與來源

- **修正 YouTube 直播暫停或靜音後不會重新連線：** 狀態查詢原本讀不到結果，直播中斷一下就會停止；現在會正確判斷直播仍在進行並自動重連。
- **X Space：** 支援 X 新的 14 字元 Space ID；暫時出現「Space not found」時會自動重試。
- **可單獨更新 yt-dlp：** 「一般設定」可以只更新 yt-dlp（下載檔會經過 SHA-256 驗證），網站改版時不必等程式更新。
- 「檢查來源」遇到中日文檔名的損壞影音檔時，會正確顯示「影音格式無法解析」，不再檢查失敗；錯誤訊息中的簽名網址會先遮蔽再截斷，不會露出部分金鑰。

### 介面

- **主視窗改用 WebView2：** 使用 Windows 內建的 WebView2 顯示控制介面，捲動與切換頁面更順暢。若電腦無法使用 WebView2，會自動改回原本的介面引擎。
- **字幕預設字級改為 16：** 只影響尚未儲存過字級的設定，已調整過的字級不變。
- 設定頁開啟更快（啟動時預先偵測顯卡）；啟動時會快取引擎檢查結果，啟動更快，日誌也更精簡。
- 術語表自動儲存不再卡在「儲存中」，分類預設收合。
- 音訊切段長度填錯時會擋下並提示；儲存失敗時，會在後端恢復後自動重送。
- 對話框背後不再使用模糊效果，避免畫面卡頓。

## 改善與修正

- **CPU 語音辨識元件版本檢查：** CUDA／ROCm 版搭配 CPU 語音辨識時，若 CPU ASR 元件版本過舊，會明確提示重新安裝，不再出現籠統的錯誤。
- **設定檔權限：** 若 `config.yaml` 已限制存取權限，儲存設定與更新時建立的備份都會保留相同限制。
- **llama.cpp：** 能正確辨識新版 llama-server 的版本號；GPU 狀態某個欄位讀不到時，仍會顯示其他欄位。
- **啟動訊息：** 不再出現「Skipping unsupported CLI arg」與「--gpt_base_url is deprecated」等多餘警告。
- **工具輸出編碼：** yt-dlp、ffprobe 與 Cookies 匯出的訊息一律以 UTF-8 讀取，中文 Windows 不再出現亂碼或解碼錯誤。
- **延遲診斷：** 翻譯重試的時間如實計算，並把每次翻譯請求記錄在 `logs/translation_requests.jsonl`，方便排查字幕延遲。

## 升級須知

- **CUDA／ROCm 版搭配 CPU 語音辨識的使用者：** 本版更新了辨識引擎，請一併安裝 `StreamTranslator-CPU-ASR-Sidecar-v1.6.1.zip`（或在程式提示時重新安裝 CPU ASR 元件）。CPU 版不需要另外安裝。
- **WebView2：** Windows 10／11 通常已內建 WebView2 Runtime。若想改回原本的介面引擎，可在 `config.yaml` 的 `ui` 區段設定 `webview_engine: qtwebengine`。
- 設定檔格式沒有改變，可以直接沿用 v1.6.0 的 `config.yaml`。

## 下載與版本選擇

| 套件 | 適用情境 |
| --- | --- |
| CPU | 使用 CPU 語音辨識，或搭配線上翻譯服務 |
| CUDA | 使用支援 CUDA 的 NVIDIA 顯示卡 |
| ROCm Experimental | AMD 實驗性版本；相容性依顯卡、驅動與模型而異 |

- **新安裝或切換套件類型：** 下載對應的 Full 完整包。
- **更新既有安裝：** 下載與原安裝類型相同的 App Update 更新包。
- **CPU ASR Sidecar：** 供 CUDA／ROCm 版使用 CPU 語音辨識；CPU 完整包無須另外安裝。

分割成多個分卷的檔案，請下載同一套件的全部分卷並放在同一資料夾。完整包可使用 `merge-full-package.bat` 合併；更新包可在手動更新器直接選擇 `.zip.part01`。

## 更新方式

1. 備份 `config.yaml`、Cookies、術語與自訂規則，停止正在執行的辨識與翻譯任務。
2. 下載對應的 App Update 及 `SHA256SUMS-v1.6.1.txt`；使用分割包時，請確認所有分卷已下載完成。
3. 開啟手動更新器，選擇 ZIP 或 `.zip.part01`，依畫面提示完成更新。
4. 更新後確認版本為 **v1.6.1**。

## 使用提醒

- 指定應用程式收音需要 Windows build 20348 以上。瀏覽器可能共用程序，無法保證只擷取單一分頁或視窗的音訊。
- ASR 提示詞與誤辨修正只能改善常見專有名詞，無法修正所有聽錯的內容。
- 直播來源仍可能受網站變更、地區限制、登入狀態與 Cookies 影響。
