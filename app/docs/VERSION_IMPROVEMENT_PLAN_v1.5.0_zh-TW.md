# Stream Translator v1.5.0 重點改善計畫

- 建立日期：2026-09-27
- 狀態：原始碼實作進行中；P0 主要骨架已完成，自動測試通過，真實桌面／模型／發布門檻待驗
- 版本主題：更容易開始、更清楚知道狀態、更可靠的多來源、多模型即時字幕
- 範圍：新手導引、輸入來源與字幕狀態、多模型相容性、VAD 切片與延遲可觀測性
- 本文件不代表已核准變更預設參數、打包或發布。

## 1. 版本目標與範圍

v1.5.0 優先讓新使用者完成第一段字幕，並讓既有使用者理解沒有字幕或等待過久的原因。涵蓋直播網址、本機影音檔、系統音訊與麥克風，並依各辨識引擎的能力提供設定與狀態；本版先聚焦流程、相容性與延遲。

三個主要成果：

1. 新手只準備所選語言與翻譯方式需要的資源，完成對應的輸入來源測試後即可開始。
2. 首頁能指出目前缺少什麼、正在處理哪一步，以及如何恢復；字幕等待時間有完整量測。
3. 驗證既有多種辨識引擎的啟動、語言與切片相容性，避免單一模型設定影響其他模型。

承接 v1.4.10 的跳過設定、本機資源、自訂 Runtime 與診斷功能；這些已有原始碼工作，不重複列為全新功能，但必須在 v1.5.0 的完整流程及發佈包中驗收。現有未提交變更應先盤點，保留使用者設定與模型，不以重置工作區整合版本。

## 4. 新手流程設計

### U1：先完成一種用途

建議順序：選擇用途 → 輸入／目標語言 → 本機或雲端翻譯 → 確認準備內容 → 測試輸入來源 → 開始字幕。

- 用途使用「電腦播放的聲音」「麥克風」「影音檔案」「直播網址」等文字。
- 保留簡單／進階模式；進階、本機資源及稍後設定均可直接進入。
- 依語言、硬體與使用者選擇準備必要 ASR 模型，其他模型首次使用時才提示下載。涵蓋專案既有引擎，不將 Qwen 或任何單一模型設為唯一選擇。
- 下載前顯示項目、已存在資源、已知下載大小、儲存位置與可用空間；未知大小明示未知，不猜測完成時間。
- 本機／雲端比較說明網路需求、下載量，以及實際送往雲端的資料種類；不得暗示雲端一定免費。
- 切換語言不刪除舊模型；已通過檢查的資源重用。

### U2：首頁準備清單

首頁準備清單只呈現能由現有狀態直接確認的音訊來源與辨識模型。翻譯連線仍在啟動／首次請求時驗證，字幕視窗仍由實際開啟與範例預覽操作，不以長期「未知」卡片冒充自動檢查。按鈕停用時緊鄰顯示原因；未設定翻譯不應阻止可用的純辨識模式。

略過導引後，首頁提供「繼續設定」，保留已完成項目。切換簡單模式不得默默改寫使用者的語言、模型或自訂路徑；需要變更時先呈現將套用的選擇。

### U3：輸入來源測試與字幕預覽

- 直播網址：檢查網址格式、解析結果及串流音訊取得，區分不支援、無法存取、尚未開播與連線中斷；依實際錯誤呈現，不猜測原因。
- 本機影音檔：檢查檔案可讀、音軌與解碼，區分不存在、無音軌與格式錯誤。
- 系統音訊與麥克風：使用下列收音測試；網址與檔案流程不要求選擇收音裝置。

- 收音測試由使用者按下開始，提供音量條、收到音訊／偵測到人聲的獨立狀態與停止操作。
- 無聲時提示播放影片、檢查輸出裝置或麥克風；收到聲音不等同模型已能辨識。
- 測試預設不保存音訊、不呼叫雲端翻譯；離開測試時釋放裝置、串流連線與檔案解碼資源。
- 提供授權明確的短範例音訊作為可選辨識測試，與真實裝置測試區分。
- 提供標示為範例的字幕預覽，讓使用者調整位置、大小與透明度；結束預覽後清除範例，不混入匯出紀錄。

### U4：下載與錯誤恢復

進度區分下載、檢查、解壓／安裝、啟動測試與完成。不可中斷的階段須明示；離開導引時避免後台任務繼續改寫設定或跳回設定頁。

錯誤至少區分：服務未啟動、網路／憑證、空間不足、資源不完整、API 金鑰或額度、模型載入失敗、網址解析／串流取得失敗、檔案讀取／解碼失敗、音訊裝置失效。每項先顯示可理解的原因及下一步，再提供技術詳情。

保留 WARP 說明於首次模式頁的「下載慢或失敗？」展開區，不把它表現為必要安裝步驟。憑證錯誤不以關閉驗證解決。診斷匯出仍放在進階設定／疑難排解，正常錯誤畫面可連到該頁。

### U5：文字與可讀性

- 「翻譯模型／後端」改為主要顯示「翻譯方式」，模型資料放入詳細資訊。
- 重要說明避免使用 9–10 px 小字；以至少 14 CSS px 為主要提示起點，配合實際桌面視窗驗證。
- 測試 100%、125%、150% 顯示縮放、鍵盤操作、可見焦點與文字對比；狀態使用文字，不只依賴顏色。
- 本機模型與 Runtime 欄位加入原生檔案／資料夾選擇，保留手動路徑輸入；驗證後顯示辨識出的資源。

## 5. 多模型與 VAD 相容性

### Q1：建立支援能力與測試矩陣

以專案實際已有的辨識引擎為範圍，例如 Qwen、Parakeet、SenseVoice、Whisper 系列等；實作前盤點各套件實際可用的引擎，不將列名視為所有套件皆已支援。

- 記錄各引擎支援語言、CPU／GPU、Runtime、模型格式與必要資源。
- 記錄是否支援自動語言、指定語言、context 等選項；不支援者隱藏或說明，不默默忽略。
- 以直播網址、本機影音檔、系統音訊、麥克風建立來源取得至字幕顯示的回歸案例。
- 共用來源層可分層測試，但每種來源與每個受支援引擎均須有代表性端到端案例；不相容組合須明示。
- 保存模型版本、參數、環境、來源及測試結果，檢查啟動、停止、重啟、錯誤恢復與資源釋放。
- 辨識準確率評分、人工校訂語料建置及排名實驗暫不列入本版工作或發佈門檻。

### Q2：切片與參數行為

1. 檢查各引擎與切片模式的有效參數，模式切換後清楚顯示哪些設定生效。
2. 驗證自然 END、短片段、硬上限及最後 flush，來源結束時不得遺留待處理音訊。
3. 檢查前綴保留與重疊去重的功能回歸，避免切片調整造成重複字幕或誤刪。
4. 各引擎獨立驗證；不得把單一模型的切片參數套用到全部模型。
5. 保留目前預設；調整候選須有功能回歸與延遲證據，沒有足夠證據則不變更。

原生模式不生效的目標段長設定應隱藏或標示不適用；若新增目標策略，使用不同明確名稱及開關。本版不承諾辨識準確率提升。

## 6. 延遲與運行狀態

### L1：從來源取得到真正顯示

分別記錄網址解析／串流取得、檔案開啟／解碼、裝置開啟的準備時間。檔案離線處理另記處理速度與總耗時，不與即時來源的等待時間混算；媒體時間戳與處理時間分開記錄。

保留既有各階段指標，新增首次語音到第一版字幕顯示、語音結束到最終字幕顯示、第一版到定稿、佇列內音訊秒數及最舊工作等待時間。

以 segment／trace ID 串接後端與前端，區分字幕交付和渲染確認。不同程序的單調時鐘不可直接相減；採經驗證的時鐘對應或各程序內耗時與訊息確認方式，明示估計誤差。原文與譯文分別量測。

每段算完完整耗時後再取 P50／P95，不相加各階段百分位數。ASR-only 與 ASR＋翻譯結果分表；本機與雲端翻譯分開。

運行文字依來源區分解析網址中、連接串流中、讀取檔案中、等待裝置聲音，再接收到音訊、辨識中、翻譯中、字幕已顯示；只顯示有實際事件支持的狀態。訊號不足時顯示未知，不用假進度。

建議性能驗收：固定硬體、來源、模型及暖機條件下，各候選至少三次重播；第一版顯示及語音結束到定稿 P95 相較基準退步不得超過 10%，否則保留為非預設方案。30 分鐘代表性連續播放後，佇列不得持續累積；報告冷啟動、RAM／VRAM 峰值與錯誤退出情況。絕對延遲目標待完整基準建立後訂定，不承諾所有設備低於一秒。

## 7. 暫不納入核心承諾

- 全面改用新 ASR 模型、MOSS 或說話者分離。
- 全面改為原生串流辨識、草稿／修訂字幕。
- 所有模型共用固定 3 秒或 6 秒切片預設。
- 用 LLM 自動改寫原文來掩蓋 ASR 錯字。
- 未經場景測試就加入強力降噪或音樂區硬丟棄。
- 大規模視覺重做、與首次字幕成功無關的設定擴充。

AED 音樂輔助及省資源／品質優先方案可以隔離實驗，但必須驗證 BGM 加人聲不被誤刪，以及硬體相容性，才考慮後續上線。

## 9. 驗收矩陣與發佈門檻

### 新手驗收

- 至少 5 位未使用過本工具的測試者，至少 4 位能在無口頭協助下完成第一段真實字幕。
- 預先備妥必要資源時，以 5 分鐘內完成首次字幕為目標；另記錄空白安裝的下載與環境準備時間，不混算或隱藏。
- 覆蓋直播網址、本機影音檔、系統音訊、麥克風，以及單一語言、切換語言／模型、本機翻譯、雲端翻譯、純辨識、已有資源、完全離線、下載失敗與重新啟動後繼續。
- 驗證無效網址、串流中斷、檔案不存在／解碼失敗、靜音、錯誤裝置、裝置中途移除、模型缺檔、後端未啟動、API 失敗；錯誤訊息提供正確下一步。

### 程式與桌面驗收

- 對按需下載、任務取消、設定保存、模型選取、追蹤時間與短句 flush 執行針對性回歸測試。
- 完成前端型別／建置檢查與相關後端測試；再驗證 Qt 桌面實際檔案選擇、字幕視窗及診斷保存路徑。
- 舊設定缺少新增欄位時使用相容預設；自訂路徑、API 設定與模型不被升級重置。
- 用基準配置與候選配置分別完成長時間運行；失敗不得只以平均延遲良好判定合格。

### 包裝與升級驗收

僅在後續明確授權打包後執行 CPU／CUDA／ROCm Full 與 App Update 檢查。每個發佈 EXE 執行健康檢查；Full ZIP 新目錄解壓測試，分割檔重組及雜湊核對。至少從當時已發布的受支援版本驗證真實升級，確認舊程序結束、檔案替換、失敗回復及設定／模型保留。

發布另需明確授權。測試報告分列原始碼、桌面執行、包裝、升級及遠端資產驗證，不以其中一層成功替代其他層。
