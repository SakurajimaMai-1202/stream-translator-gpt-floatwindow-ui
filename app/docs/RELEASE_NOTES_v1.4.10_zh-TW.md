# Stream Translator v1.4.10 更新說明

v1.4.10 改善首次設定、離線資源、輸入來源檢查與打包版 CUDA ASR。提供 CUDA、CPU、ROCm Experimental 三種套件；請依電腦硬體選擇相同 Profile 的 Full package 或 App Update。

## 首次設定與離線使用

- 首次啟動可以選擇「稍後設定，先進入程式」，不再要求先完成所有下載。
- 可使用本機已有的 ASR 模型目錄、`llama-server.exe` 與 GGUF 翻譯模型；驗證成功後保存路徑，不會搬移或刪除外部檔案。
- CUDA／ROCm 使用者可匯入離線 CPU ASR sidecar ZIP，不必由程式連線下載 Runtime。
- 簡單模式只準備目前所選語言需要的一個 ASR 模型，不再固定下載三個入門模型。
- 模型下載可取消；取消後不會把未完成的模型標示為可用，也不會延遲覆寫導引設定。
- SSL 或網路下載失敗時仍保留憑證驗證，可改用本機資源或稍後設定；本版不會停用 TLS 安全檢查。

## 來源測試與字幕預覽

- 直播網址會先檢查網址解析結果與可用音訊串流。
- 本機影音檔會檢查檔案、音軌及解碼能力。
- 系統音訊與麥克風會分別開啟所選裝置做短暫收音測試，不會保存測試音訊或呼叫翻譯服務。
- 首頁只顯示能自動確認的音訊來源與語音辨識準備狀態。
- 新增範例字幕樣式預覽，可先調整位置、字級、顏色與背景透明度；範例內容不會保留。

## 新安裝預設與浮動字幕

- 本機自訂模型位址、llama.cpp 伺服器啟動參數及 HY-MT2 的 llama.cpp 位址預設使用連接埠 8081；已儲存的使用者位址與連接埠維持原設定。
- 目標翻譯語言預設為繁體中文。
- 新安裝的浮動字幕預設出現在主螢幕中間下方；之後拖曳的位置會繼續保存。
- 字幕預設使用青色原文、黃色翻譯、橘色時間碼、亮綠色延遲文字，以及 5% 不透明度的白色背景。
- 字幕設定可開啟滑鼠穿透；開啟後可點擊字幕後方的視窗，仍可從主視窗的字幕設定關閉。
- 浮動字幕提供獨立的滑鼠穿透切換按鈕，穿透開啟時仍可直接點擊按鈕解除。
- 穿透切換使用圖層圖示；狀態燈與控制按鈕沿同一中心線排列，垂直間距一致。
- 字幕視窗狀態燈會在 ASR 模型載入完成、辨識管線啟動後變綠；字幕視窗會同步後端就緒狀態，避免漏接通知後持續顯示紅燈。

## ASR、VAD 與延遲資訊

- 保留 Faster-Whisper、Qwen3-ASR、SenseVoice、Fun-ASR、Parakeet 與遠端 OpenAI ASR 等既有引擎，不更換正式 ASR 或 VAD 預設。
- 加入模型能力資訊，依 Runtime Profile、語言與模型格式限制可選項目。
- 延遲追蹤新增首次語音到字幕、語音結束到定稿、前端顯示確認，以及 ASR 佇列段數、累積音訊秒數與最舊等待時間。
- 首頁執行中可查看 ASR 佇列狀態，方便辨識模型是否逐漸跟不上音訊。

## HY-MT2 日文直播翻譯

- 新增 Hololive／VTuber 雜談、料理與其他直播情境的內建詞語表，可選擇目前情境或不套用情境詞表。
- 可建立、重新命名及管理自訂翻譯情境，個人詞條可指定適用情境；切換情境只影響後續翻譯工作階段。
- 詞語管理頁會標示目前情境實際生效的個人詞條與內建詞條，並顯示同名詞條的優先順序。
- HY-MT2 優化設定提供簡化的推薦設定，同時保留進階提示與上下文參數供需要者調整。
- 翻譯設定未選擇情境詞表時維持不套用，避免改變既有翻譯設定的行為。

## 字幕輸出保護

- 避免把與目前字幕無關的前一段翻譯內容再次輸出為新字幕。
- 丟棄只有標點符號的 ASR 碎片，避免它被當成獨立字幕送去翻譯。

## 問題修正

- 修正打包版 GUI 啟動 ASR／翻譯子程序時可能繼承 Qt 或 PyInstaller DLL 路徑，導致 CUDA Runtime 載入失敗的問題。
- 外部 ASR／翻譯程序改用隔離啟動環境，同時保留 FFmpeg 路徑、工作目錄、UTF-8 與模型相關環境變數。
- 保留 v1.4.9 的更新器鎖檔等待、原子替換、失敗回復及原生 OmniStreamVAD 行為。
- 改善首頁說明、鍵盤可見焦點與主要文字對比。

## 診斷與本機資源

- 「進階設定／疑難排解」可匯出 Runtime 診斷 JSON，內容不包含 API Key、Cookie、字幕或測試音訊。
- 新 Full 與 App Update 不再附帶工程用的 `smoke_sensevoice_asr.ps1` 與 `diagnose_runtime.ps1`；診斷改由程式介面匯出。
- Full package 不包含大型 ASR／GGUF 模型，也不內附 llama.cpp Runtime；只會在使用者選擇後按需準備。

## 套件選擇

- **CUDA**：NVIDIA 顯示卡使用。
- **CPU**：沒有相容 GPU，或希望使用 sherpa-onnx CPU ASR 時使用。
- **ROCm Experimental**：相容 AMD 硬體的實驗性套件，實際支援仍取決於顯示卡與驅動。
- App Update 只能套用到相同 Profile。CPU、CUDA、ROCm 之間切換必須使用對應 Full package。

v1.4.10 App Update 使用 `runtime_replace`，會帶入完整且與 Profile 相符的 Runtime，以確保 CUDA DLL 隔離、ASR 佇列量測及最新管線程式碼真正生效。更新器會先備份並在啟動失敗時嘗試回復。最低可直接升級版本為 v1.3.11；更舊或無法識別的安裝請改用 Full package。

## 更新方式

### 新安裝或跨 Profile

1. 下載硬體對應的 Full package 全部分割檔。
2. 將分割檔與 `merge-full-package.bat` 放在同一資料夾後執行合併。
3. 以 `SHA256SUMS-v1.4.10.txt` 核對合併後 ZIP。
4. 解壓縮到新的資料夾，再執行 `Stream Translator.exe`。

### 從 v1.3.11 以上的同 Profile 更新

1. 備份舊安裝的 `config.yaml`、Cookies、術語及自訂規則。
2. 關閉 Stream Translator，確認舊視窗及後端已停止。
3. 下載與目前安裝相同 Profile 的 App Update；若檔案被分割，先使用合併腳本還原 ZIP。
4. 由程式更新介面套用，或依套件內說明操作。
5. 更新後確認版本為 v1.4.10，再測試原本使用的來源、ASR 與翻譯方式。

## 已知限制與尚待實機驗證

- 麥克風是否能成功開啟仍受 Windows 音訊後端、裝置占用與權限影響；程式會顯示實際錯誤與處理方向。
- 不同 CPU／CUDA／ROCm 硬體上的所有 ASR 模型組合無法由單一測試機完整覆蓋。
- 125%／150% 顯示縮放、長時間連續執行、真實舊版升級與各 Profile 模型推論需在對應環境繼續驗收。
- 本機自動測試或套件健康檢查通過，不等同所有模型、裝置與網路服務均已驗證。
