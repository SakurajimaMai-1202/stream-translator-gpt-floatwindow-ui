# Stream Translator v1.6.0

發布日期：2026 年 10 月 18 日

本次更新重新設計術語表、簡化本地翻譯設定，並大幅改善字幕中殘留日文假名、ASR 聽錯專有名詞的問題，同時加強安全性與穩定性。

## 主要更新

### 術語表重新設計

- 翻譯詞條與 ASR 修正規則合併為**同一份清單**：一筆詞條可同時填寫譯法與常見誤辨寫法；譯法留空即只做 ASR 修正。
- 「情境」改為**可同時勾選多個分類**，內建詞條以分類呈現，可單筆停用或覆寫。
- 一行快速新增、分組內直接編輯，支援 CSV 匯入匯出。
- 內建「一般直播」常用詞（如マシュマロ、スパチャ等），所有安裝都能使用。
- 詞條會自動作為支援的 ASR 引擎提示詞（Whisper／Faster-Whisper／Fun-ASR 等，可自行關閉；Qwen3-ASR 不使用提示詞以避免幻聽）。
- **建議的常見誤辨**：開啟收集後，程式會從辨識結果中找出疑似聽錯的詞並列出，可一鍵加入或忽略。可選擇下載約 20 MB 的讀音字典，以讀音比對找出同音誤字（例如「水星」→「彗星」），準確度更高。

### 本地翻譯更容易上手

- 單一「本地翻譯」頁面取代原本三個頁面，並在頁首加入使用步驟說明。
- 推薦的翻譯模型可直接在程式內下載（可取消），並依實測顯存需求挑選模型。
- 簡單模式可用「開始設定」一鍵完成本地翻譯準備；首次設定導向可自行選擇模型。
- 模型資料夾、執行檔等路徑改用系統的選擇資料夾／檔案視窗。
- 新增 Index-Translate 支援：自動關閉思考模式、清除外洩的思考內容，並依伺服器實際載入的模型自動套用最佳化設定。
- CUDA／ROCm 預設將翻譯模型完整載入顯卡；選擇推薦模型時自動套用建議參數。
- 修正安裝版「翻譯選項」中的「測試模型連線」與「試譯」一律失敗的問題（v1.5.0 起）。
- 使用本機模型時，若「模型伺服器」誤選外部伺服器但未填模型名稱，會自動沿用本地翻譯的模型，不再連線失敗；選項更名為「外部 llama-server（自行啟動）」以免誤選。
- 新安裝的預設翻譯服務改為「本機模型」；首次設定時選擇雲端服務則照舊使用雲端。

### 字幕翻譯品質

- 大幅減少中文字幕中殘留的日文假名：常見外來語與語氣詞會自動轉成中文，殘留過多時以不同參數重試一次，不再整行空白。
- 敬稱處理更精準，不會誤改一般詞彙。
- 統一所有繁體中文變體的轉換；模型輸出為空時明確標示失敗，而不是送出空字幕。
- 上下文提示不再夾帶括號引號等符號；Gemini 2.5 Flash 預設關閉思考以降低延遲。

## 改善與修正

- **安全性：** 管理 API 只接受本機連線並需要每次啟動產生的權杖；設定中的 API 金鑰在介面與同步事件中會遮蔽；修正路徑穿越問題；llama 執行檔下載必須通過 SHA-256 驗證。區網字幕分享（8765 埠）不受影響。
- **在瀏覽器開啟控制介面：** 因管理 API 需要權杖，請改用「進階設定／疑難排解」中的「在瀏覽器開啟管理介面」按鈕。
- **介面顯示：** Windows 控制介面預設改為軟體渲染，避免破圖與黑畫面；字幕預設字級改為 18。
- **直播來源：** 直播狀態查詢失敗時不再誤判結束；VOD 播完會正確結束；重新連線後 SRT 時間軸維持正確；登入／Cookies 錯誤與 403 會給出明確提示，不再無限重連。
- **模型下載：** ASR 模型下載可取消，取消後可直接重新下載；同一模型不會重複下載。
- **更新與回復：** 中斷的更新會自動回復；檢查分割包完整性；更新失敗時保留可用的版本。
- **設定檔：** 損毀的 config.yaml 會被隔離並保留；刪除的預設不會再出現；啟動時不再改寫設定檔。
- **疑難排解：** 「進階設定／疑難排解」可匯出已去除敏感資訊的日誌壓縮檔。
- **雲端模型清單：** 「載入可用模型」後改用深色下拉選單挑選，修正清單文字是黑色、看不清楚的問題。
- **首頁：** 已選定的音訊來源不再要求重新確認；移除右上角「使用教學」按鈕。

## 升級須知

- **設定會自動轉換：** 第一次啟動 v1.6.0 時，舊的術語表與 ASR 修正規則會轉換為新格式，內容與原本相同。更新前請先備份 `config.yaml`；若轉換結果有誤，可還原備份並回報。
- **其他程式呼叫管理 API：** 若有自行撰寫的工具或其他裝置透過 8000 埠呼叫設定 API，更新後將無法連線（只開放本機並需要權杖）。
- 讀音字典為選用元件，不包含在安裝包中；需要時在「術語表 → 建議的常見誤辨」下載，更新程式時會保留。

## 下載與版本選擇

| 套件 | 適用情境 |
| --- | --- |
| CPU | 使用 CPU 語音辨識，或搭配線上翻譯服務 |
| CUDA | 使用支援 CUDA 的 NVIDIA 顯示卡 |
| ROCm Experimental | AMD 實驗性版本；相容性依顯卡、驅動與模型而異 |

- **新安裝或切換套件類型：** 下載對應的 Full 完整包。
- **更新既有安裝：** 下載與原安裝類型相同的 App Update 更新包。
- **CPU ASR Sidecar：** 供原本使用獨立 CPU ASR 元件的配置更新使用；CPU 完整包無須另外安裝。

分割成多個分卷的檔案，請下載同一套件的全部分卷並放在同一資料夾。完整包可使用 `merge-full-package.bat` 合併；更新包可在手動更新器直接選擇 `.zip.part01`。

## 更新方式

1. 備份 `config.yaml`、Cookies、術語與自訂規則，停止正在執行的辨識與翻譯任務。
2. 下載對應的 App Update 及 `SHA256SUMS-v1.6.0.txt`；使用分割包時，請確認所有分卷已下載完成。
3. 開啟手動更新器，選擇 ZIP 或 `.zip.part01`，依畫面提示完成更新。
4. 更新後確認版本為 **v1.6.0**，並到「術語表」確認詞條與分類正確。

## 使用提醒

- 指定應用程式收音需要 Windows build 20348 以上。瀏覽器可能共用程序，無法保證只擷取單一分頁或視窗的音訊。
- 控制介面預設使用軟體渲染（捲動較不流暢）；若想改用 GPU，可在 `config.yaml` 的 `ui` 區段設定 `webview_rendering: gpu-safe`。
- ASR 提示詞與誤辨修正只能改善常見專有名詞，無法修正所有聽錯的內容。
- 直播來源仍可能受網站變更、地區限制、登入狀態與 Cookies 影響。
