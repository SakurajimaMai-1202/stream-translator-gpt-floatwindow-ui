# HY-MT2 情境詞語表

設定頁「詞語表」現在可在同一處選情境、查看內建詞條，並管理個人詞條。翻譯設定頁提供目前情境摘要與入口。

| 選項 | 用途 | 詞條數 |
| --- | --- | ---: |
| 不加情境詞表 | 只沿用使用者現有術語與 JSON 資料夾 | 0 |
| 日文雜談 | 直播、連動、精華、推活等通用說法 | 7 |
| Hololive／VTuber 雜談 | Hololive 常見名稱及直播用語 | 15 |
| Cosplay 雜談 | 假髮、隱形眼鏡、服裝製作、攝影會等 | 11 |

詞條位於 `app/backend/core/hy_mt2_glossary_presets.py`。只有開啟 HY-MT2 優化，且實際模型使用 HY-MT2 策略時才加入提示詞。預設選項為「不加情境詞表」，所以既有設定與 replay baseline 不變。

原本沒有適用情境的個人詞條維持「所有直播」生效。新增詞條可選所有直播或單一情境；在選定情境內，同原詞的個人情境譯法優先於個人全域譯法。個人原詞優先於 JSON 資料夾與內建詞條；JSON 資料夾優先於個人別名及內建詞條。未選情境時，只使用個人全域詞條。內建情境詞表只在 HY-MT2 優化啟用時使用。

「管理自訂情境」可新增、改名、刪除使用者自己的情境。情境名稱與 ID 儲存在 `terminology.custom_glossary_scopes`；選取的情境仍儲存在 `translation.hy_mt2_glossary_preset`。自訂情境不帶內建詞條，使用全域詞條與該情境詞條。仍有詞條的情境不可刪除，需先移動詞條。改名不改 ID，因此原有詞條持續適用。

JSON 資料夾仍依既有方式載入，但不在設定頁預覽中計數。詞條只在當前日文文字包含原詞時送入翻譯提示，不會修改 ASR 輸出。更換選項後，下一個翻譯工作階段才會套用。

CSV 匯出使用 `original,translated,scope,aliases` 四欄。匯入仍接受舊版兩欄 CSV，缺少 `scope` 的詞條視為所有直播；相同原詞可各自有全域及情境譯法，匯入時依「原詞＋情境」合併，不會把其他情境覆蓋掉。
若有自訂情境，CSV 會在詞條前加入 `#context,id,name` 資料列；匯入時會一併建立這些情境並驗證 ID。完整設定匯出也包含情境定義。

目前詞條採保守寫法，不放容易命中普通日文的短暱稱，也不做 `タイ → 鯛` 等同音字替換。人名繁中譯法可在使用者正式術語表覆蓋；成員日文名稱以 hololive 官方名單為參照。
